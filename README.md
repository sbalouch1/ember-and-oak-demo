# Ember & Oak — Demo Restaurant Site

A polished one-page demo website for a fictional wood-fired restaurant in
Chicago's Fulton Market. Built as a portfolio sample for a productized
"restaurant website in 7 days" service.

## What's inside

- `index.html` — the entire site (styles + scripts embedded, no build step)
- `images/` — AI-generated hero, kitchen, and food photography

## Sections

Sticky nav · full-screen hero · marquee strip · story · tabbed menu ·
gallery · hours & location · reviews · reservation form · footer

## Run it locally

```bash
# Python
python3 -m http.server 8000
# then open http://localhost:8000

# or Node
npx serve .
```

## Deploy

Any static host works: GitHub Pages, Netlify, Vercel, Cloudflare Pages.
No build step — just serve the folder.
